01Robotics · Real-time systems

Real-Time Robot Following
with Obstacle Avoidance.

A safety-bounded person-following system for a legged robot. It combines UWB target localization, 3D LiDAR perception, and two distinct obstacle-avoidance modes: MPPI local planning and APF-based obstacle avoidance. A live web dashboard supports supervised operation.

  • ROS 2
  • UWB
  • 3D LiDAR
  • MPPI
  • APF
  • WebSocket
